| **Termius** | $10/month | Free SSH client |
| **DataCamp** | Paid | Free access |
| **Educative** | Paid | Free access |

**How to apply:** Sign up with your .edu email. Verification usually takes 1-3 days.

## Budget Tiers

### Tier 1: $0/month (100% Free)
- **Editor:** VS Code + GitHub Copilot Free
- **AI Assistant:** Gemini CLI (free, 1500 requests/day)
- **Prototyping:** Bolt.new free tier
- **Deploy:** Vercel Hobby (free)
- **Database:** Supabase free or SQLite
- **Testing:** Jest/pytest (open source)
- **CI/CD:** GitHub Actions (free)
- **Monitoring:** UptimeRobot free

### Tier 2: $0/month (Student Discounts Applied)
Everything in Tier 1, PLUS:
- **Editor:** Cursor Pro (free 1 year via student discount)
- **AI Assistant:** GitHub Copilot Pro (free via Student Pack)
- **Monitoring:** Sentry (free via Student Pack)
- **Extras:** 1Password, Azure credits, JetBrains IDEs

### Tier 3: ~$20/month (If You Have Budget)
Everything in Tier 2, PLUS:
- **AI Assistant:** Claude Code or Claude Pro subscription
- **Deploy:** Railway Pro ($5/month) for always-on backend
- **Prototyping:** Bolt.new or Lovable paid tier for more generations

## Important Notes

1. **Never pay for something with a free tier** until you've outgrown the free tier
2. **Apply for the GitHub Student Pack first** — it unlocks the most value
3. **Gemini CLI is your best friend** for $0 budget — 1500 free requests/day with Gemini 2.5 Pro
4. **Tools change constantly** — by the time you graduate, half of these will have new pricing. The skills you learn are permanent.
5. **Ask in class** if you're unsure about costs — we'll always find a free path
