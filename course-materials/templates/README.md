## PRD Examples

The [examples/](examples/) folder contains 24 ready-to-use PRDs covering a wide range of project types:

**Beginner** — Todo CLI, Password Generator, Unit Converter, Pomodoro Timer, and more

**Intermediate** — Bookmark Manager, Habit Tracker, RSS Aggregator, Expense Tracker, and more

**Advanced** — Real-time Chat, Finance Dashboard, SaaS Starter, AI Code Review, and more

Most examples follow the full course PRD structure: Overview, Core Features, Non-Goals, Technical Constraints, Success Criteria, Implementation Phases, and Agent Rules.
