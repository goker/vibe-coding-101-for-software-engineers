## PRD Template Structure

Every PRD in this library follows this structure:

```markdown
# PRD: [Project Name]

> **Difficulty:** X | **Type:** X | **Time:** X

## Overview
| What | Who | Why |

## Core Features (MVP)
1. Feature 1
2. Feature 2
3. Feature 3

## Non-Goals ← CRITICAL FOR AI
**Will NOT build:** [explicit list]
**Will NOT use:** [explicit list]

## Technical Constraints
| Language | Framework | Dependencies | Testing |

## Success Criteria
- [ ] Measurable criterion 1
- [ ] Measurable criterion 2

## Implementation Phases
### Phase 1: [Name]
**Goal** | **Tasks** | **Verification** | **Deliverables**

## Agent Rules
| Always | Ask First | Never |
```

## How to Use These Examples

1. **Choose by difficulty** — Start with Beginner if new to AI coding
2. **Copy the template** — Use as starting point for your own project
3. **Customize Non-Goals** — Add your specific boundaries
4. **Feed to AI** — Share PRD with Claude Code or Gemini CLI
5. **Follow phases** — Build incrementally with verification
