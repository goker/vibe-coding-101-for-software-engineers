## What You'll Learn

This course teaches computer engineering students how to leverage AI-assisted development — commonly known as "vibe coding" — while maintaining professional software engineering discipline. You'll learn to use **any AI coding tool** (Cursor, Claude Code, Windsurf, Gemini CLI, Copilot, Bolt.new, v0, and more) following universal best practices that transfer across the rapidly evolving tool landscape.

**This course is tool-agnostic by design.** Tools change every 3 months; disciplines last decades.

You'll build **one evolving product** across the entire semester: prototyping in Week 3, hardening through Weeks 5-8, and launching publicly by Week 12.

---

## Learning Outcomes

Upon successful completion, you will be able to:

1. **Understand how LLMs generate code** and why hallucinations, security vulnerabilities, and architectural issues occur
2. **Apply the Explore → Plan → Code → Verify cycle** using any AI coding tool
3. **Write comprehensive test suites** for AI-generated code and integrate them into CI/CD pipelines
4. **Design maintainable software architecture** that guides AI toward good patterns
5. **Identify and mitigate AI-specific security risks** including package hallucination and prompt injection
6. **Build and deploy production-ready applications** with monitoring, error handling, and observability
7. **Create reusable skills and multi-agent systems** for automated engineering workflows
8. **Present and launch** a real product to real users

## Two Milestones

### Milestone 1: Mid-term Checkpoint (Week 6)

Present your product's architecture and progress:
- Working prototype with core features
- Test suite demonstrating code quality
- Architecture documentation (diagram + decisions)
- 5-minute presentation to the class

### Milestone 2: Demo Day (Week 12)

Launch your product publicly:
- Deployed product URL (live and working)
- Source code repository with README
- 5-minute presentation + 2-minute demo video
- Evidence of real user feedback
