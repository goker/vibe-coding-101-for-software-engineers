## Learning Objectives

By the end of this week, students will be able to:

1. **Explain the history and evolution** of AI-assisted coding ("vibe coding")
2. **Define "disciplined vibe coding"** and distinguish it from undisciplined approaches
3. **Write a complete PRD** before any AI-assisted coding
4. **Set up Claude Code** and verify proper installation
5. **Execute their first Claude Code session** with proper context

## Lab Exercise

### Objective
Write a PRD and build a simple greeting CLI using Claude Code.

### Deliverables
1. Completed PRD for greeting CLI
2. Working CLI that:
   - Accepts a name as input
   - Returns a personalized greeting
   - Handles edge cases (empty name, special characters)
3. Screenshot of successful Claude Code session

### Time Allocation
- PRD writing: 20 minutes
- Claude Code implementation: 25 minutes
- Testing and refinement: 15 minutes

## Key Takeaways

1. **Vibe coding** is a legitimate development paradigm when practiced with discipline
2. **PRDs are essential** - AI cannot infer your intentions from omission
3. **Non-goals are critical** - Explicitly state what you're NOT building
4. **Environment setup** is foundational - Get it right from day one
