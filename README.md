# Vibe Coding 101 for Software Engineers

> "There's a new kind of coding I call 'vibe coding', where you fully give in to the vibes, embrace exponentials, and forget that the code even exists." — Andrej Karpathy, February 3, 2025

A **12-week course** teaching disciplined AI-assisted development for software engineers. Learn to harness any AI coding tool — Cursor, Claude Code, Windsurf, Gemini CLI, Copilot, Bolt.new, and more — while maintaining professional engineering standards.

**This course is tool-agnostic.** Tools change every 3 months. Disciplines last decades.

## Key Concepts

**Disciplined Vibe Coding** — Harnessing AI speed while maintaining professional standards: testing, architecture, security, and code review.

**Context Engineering** — The successor to prompt engineering. Organizing all information (not just prompts) so AI can solve problems effectively.

**The EPCV Cycle** — Explore → Plan → Code → Verify. The universal workflow for AI-assisted development, applicable in any tool.

**PRD-First Development** — Every project starts with a Product Requirements Document. AI cannot infer from omission.
